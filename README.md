# NovaHealth — React Mock Project

A polished, responsive healthcare landing page built as a portfolio project for freelance front-end work.

## What the project demonstrates
- Responsive layout across desktop, tablet, and mobile
- React component-driven UI
- Semantic HTML structure
- Responsive CSS with Flexbox and Grid
- Accessible labels and button states
- Interactive mobile navigation
- Light/dark theme toggle
- Appointment form with client-side success feedback
- Clean, reusable styling and clear project structure

## Tech stack
- React
- JavaScript
- HTML5
- CSS3
- Vite

## Run locally
```bash
npm install
npm run dev
```

## Build for production
```bash
npm run build
```

> Note: This is a fictional mock project. The appointment form is front-end only and does not send data to a backend.
